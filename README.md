# Bot afk v1
Bot AFK Minecraft (Mineflayer) dengan dashboard web control 

## Install

```bash
git clone https://github.com/Hamzz559/BotAfk
cd BotAfk
npm install
node index.js
```

Jalan berikutnya cukup Enter buat pakai data sebelumnya, atau ketik yang baru.
IP bisa pakai port, contoh `play.example.com:25565`.
